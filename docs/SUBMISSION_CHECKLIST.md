# Presentation-machine checklist

- Pull `origin main`; install Python 3.12 constrained development requirements.
- Run `python scripts/check.py` from the project root.
- Run the C02, C06 and C13 modules for fresh evidence if desired.
- Start Streamlit and complete the README judge walkthrough.
- Check the visible synthetic/provenance labels and current data dates.
- Export a decision audit and the C13 scenario you actually present.
- For historical mode, refresh the price cache before review.
- Keep .env, PDFs and local databases out of the submission archive.
- Read QA_REPORT.md and state its limits accurately; licensing remains pending.
- Keep an offline recording or screenshots as a presentation backup.
